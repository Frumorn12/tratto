# Publishing on the official F-Droid store

`it.frumorn.tratto.yml` is the build recipe for [fdroiddata](https://gitlab.com/fdroid/fdroiddata). It builds the **libera** flavor (free software only) from the `v1.0.0` tag and checks new tags for updates. It passes `fdroid lint` and `fdroid rewritemeta`.

Notes for reviewers:

- The `completa` flavor links Google ML Kit and Play services through `completaImplementation`; the `libera` flavor has none of them (checked on the APK: no `com.google.android.gms` or `com.google.mlkit` classes, no INTERNET permission).
- `hershey.bin` is font data (the public-domain Hershey single-stroke fonts, see `docs/Hershey-fonts.txt`) generated by `tools/font_hershey.py`. Only the `completa` flavor uses it, so the recipe deletes it before building. From 1.0.1 on it lives in `app/src/completa/assets`.
- The release is unsigned when `~/.config/tratto/firma.properties` is missing, which is the case on the F-Droid build server.

To submit: fork fdroiddata on GitLab, copy the file to `metadata/it.frumorn.tratto.yml`, commit "New app: Tratto" and open a merge request with the *App inclusion* template.
